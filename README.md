## Project 1: BMI Calculator

**What it does:** 
Calculates Body Mass Index from user’s weight and height, and tells if person is Underweight, Normal, or Overweight.

**Formula used:**
`BMI = weight / (height - height)`
Weight in kg, Height in meters

**BMI Categories:**
- < 18.5  → Underweight
- 18.5 to 24.9 → Normal
- >= 25 → Overweight

**Python Concepts Learned: **
- `input()` → To take data from user
- `float()` → To convert text to decimal numbers
- `**` → For power, like height squared
- `if / elif / else` → For decision making
- `f-string` → For formatted output
- `:.2f` → To round BMI to 2 decimal places
